# 자동 던전 RPG

자동으로 던전을 내려가는 방치형 RPG. 빌드 과정 없이 도는 단일 HTML 파일.

- 현재 빌드: **M5-01**
- 실행: `index.html` 을 브라우저로 열거나 GitHub Pages 라이브 URL 접속
- 저장: 브라우저 `localStorage` (`dungeon_save_v5`, 이전 `v4`/`v3`/`v2`/`v1` 세이브 자동 이어받기)

## 진행 단계
- **M1**: 영웅 1명이 적 1명과 자동 전투하는 최소 뼈대. 영웅은 무조건 이기고 적은 반격하지 않는다.
  공격주기마다 적 체력을 깎아 처치 → 골드 획득 → 다음 층 적 등장(체력 ×1.15).
- **M2**: 골드로 영웅 강화. 공격력 강화(+5, 비용 ×1.5), 공격속도 강화(−0.05초, 하한 0.2초, 비용 ×1.8).
  골드 부족 시 버튼 비활성. 골드 소비처(sink) 도입.
- **M3**: 매 10층마다 **보스 관문**(체력 ×8, 제한시간 30초). 시간 내 처치 → 큰 보상(일반 골드 ×20)+진행,
  실패 → 직전 구간으로 복귀해 farming → 강화 후 자동 재도전. 일반 골드 층 비례(정체 완화), 최고 층 기록.
- **M4**: 새 재화 **보스 정수 💠**(보스 시간 내 처치 시에만 드랍, 깊을수록 ↑). 정수로 **데미지 배수**(곱셈) 강화.
  최종 데미지 = (기본 + 공격력 강화) × 배수(1.1^레벨). 곱하기 벽을 곱하기 성장으로 부분 돌파.
- **M5**: 대규모 업데이트 5종.
  ① **오프라인 보상** — 자리 비운 시간만큼 골드 추정 지급(최대 8시간, 상점으로 +1h/레벨).
  ② **초기화** — 진행 데이터 리셋(보석·영구 상점은 유지).
  ③ **경험치 → 레벨업** — 적 처치 XP(일반 +1·보스 +10), 자동 레벨업 시 스킬 포인트 +1·기본공격력 +1.
  ④ **스킬 3종** — 황금 손(골드 +5%/Lv), 정수 친화(정수 +1/Lv), 강타(10초마다 평타 ×(2+Lv) 자동).
  ⑤ **희귀 보석 💎 → 영구 상점** — 일반 1%·보스 +1 드랍. 골드 +10%/Lv, 데미지 +5%/Lv, 오프라인 상한 +1h/Lv. 초기화해도 유지.
